# 🤖 AI Chatbot Project

A modern AI-powered chatbot built with React, Tailwind CSS, and API integration.  
This chatbot provides smooth conversation experience with typing animation, markdown support, and sound effects.

## 🚀 Features

- 💬 Real-time chat system
- 🤖 AI-powered responses
- ⌨️ Typing indicator animation
- 🔊 Sound effects for messages
- 📝 Markdown support (bold, links, code, etc.)
- 📱 Fully responsive design
- 🎨 Clean modern chat UI

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Axios
- React Markdown
- Django API (backend)
